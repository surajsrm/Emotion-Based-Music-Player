# Emotion Based Music Player 🎵

An AI-powered web application that detects a user's facial expression through a webcam and automatically plays music based on the detected emotion using YouTube integration.

---

## 📌 Project Overview

Emotion Based Music Player is a real-time mood detection web application built using React and Face API.  
The system scans facial expressions through the user's webcam, identifies emotions such as happy, sad, angry, neutral, and surprised, and then plays matching music automatically.

The project combines:
- Facial Emotion Detection
- AI-based Expression Recognition
- Real-Time Webcam Processing
- YouTube Music Streaming
- Interactive User Interface

Webcam captures live facial expressions
Face API analyzes the expression
Emotion is detected
Matching music is selected
YouTube player streams the song.
